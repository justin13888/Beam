## [1.0.0](https://github.com/justin13888/Beam/compare/v0.1.0...v1.0.0) (2026-09-02)


### ⚠ BREAKING CHANGES

* **client:** `BeamError::Server` gains a `retryable` field, so a foreign caller pattern-matching that variant has one more binding.
* **client-core:** `BeamError::{BadRequest, Forbidden, NotFound, Server}` gain a `code` field carrying the problem document's `type`, or
* **server:** serve artwork URLs from Beam, not the provider CDN
* **server:** every problem document's `type` URI changes. A client branching on the old status-shaped codes must move to the new ones; the statuses themselves are unchanged apart from the two phantoms above.
* **compose:** make the dev Dex opt-in and reachable from the server container
* **client-core:** every generated type and method in `beam-client-core`'s public `api`/`wire` modules is renamed. The UniFFI boundary is unaffected.
* **server:** a 429 is now an RFC 9457 problem document rather than `{"error": "Rate limit exceeded"}`, matching every other error on `/v1`, and carries `X-RateLimit-Limit`, `-Remaining` and `-Reset` alongside `Retry-After`.
* **server:** restore the route table and serve it on the Kynos runtime
* **server:** `GET /metrics` answers 503 rather than 404 when BEAM_ENABLE_METRICS=false, and appears in the exported OpenAPI document. The router shape no longer depends on configuration, which is what keeps the document true of every deployment it describes.
* **server:** swap Salvo for Kynos and free beam-auth of the framework
* **auth:** BEAM_ADMIN_EMAILS is removed. Admin is now granted only by an IdP-asserted ID-token claim configured via BEAM_OIDC_ADMIN_CLAIM (matched per BEAM_OIDC_ADMIN_VALUE). Operators must configure their IdP to release the claim (e.g. a Dex/Keycloak group) and set BEAM_OIDC_ADMIN_CLAIM=groups BEAM_OIDC_ADMIN_VALUE=beam-admin. Until BEAM_OIDC_ADMIN_CLAIM is set, no user is admin, and any existing admin is demoted at their next login.
* **config:** every beam-server env var is now BEAM_-prefixed -- BEAM_BIND_ADDRESS, BEAM_SERVER_URL, BEAM_DATABASE_URL, BEAM_VIDEO_DIR, BEAM_ENABLE_METRICS, BEAM_HASH_UNKNOWN_FILES, BEAM_SCAN_INTERVAL_SECS, BEAM_WATCH_ENABLED, BEAM_WATCH_DEBOUNCE_MS, BEAM_ENRICH_INTERVAL_SECS, BEAM_TMDB_API_TOKEN, BEAM_ANILIST_ENABLED -- and CACHE_DIR is now BEAM_DATA_DIR (config field data_dir, container path /data, compose volume server_data, host-side HOST_DATA_DIR). Compose-only STREAM_HOST_PORT is now BEAM_SERVER_HOST_PORT. No deprecation aliases: pre-alpha, and the docs had already ratified the BEAM_DATA_DIR shape.
* **auth:** cut over to cookie-only OIDC, delete legacy password/JWT/stream-token auth
