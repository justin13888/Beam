## Outcome

A credentialed cross-origin request can read a Beam response only from the web origin the operator configured. The session and OIDC-state cookies' attributes are pinned by tests: `HttpOnly`, `SameSite=Lax`, `Path`, `Max-Age`, and `Secure` when configured. The login redirect guard is proven end to end.

## Findings

- **server-TEST-002** `beam-server/src/bootstrap.rs:83-110`. `cors_policy()` is `allow_origins_matching(|_| true)` with `allow_credentials()`, so any origin is mirrored back with `Access-Control-Allow-Credentials: true`. The router comment (`routes/mod.rs:200-214`) calls this safe only because `EnforceSameOrigin` rejects cross-origin *writes*. Safe methods are never checked (`middleware_tests.rs:141`). A same-site sibling origin (for example another subdomain under the same registrable domain), whose requests do carry a `SameSite=Lax` cookie, can therefore read `GET /v1/me`, `/v1/sessions` and the library. No test exercises this through `create_router`.
- **server-TEST-001** `beam-server/src/routes/auth.rs:603-611` (`build_cookie`). No test checks the cookie attributes. Deleting `.http_only()` or `.secure()` fails nothing. `auth_tests.rs:314-324` checks only that the state cookie is non-empty.
- **server-TEST-010** `beam-server/src/routes/auth.rs:664-698`. The open-redirect guard is tested only as a pure function (`auth.rs:1226-1244`), never end to end. Login against an unconfigured IdP (`503`) is untested.

## Decisions taken

These are the run's decisions under the autonomy contract. Nobody has reviewed them.

1. Which origins may make credentialed CORS reads.
   Taken: only the configured web origin (the origin of the existing web-URL setting that OIDC already uses for redirects), plus any origin a new list setting names if the lane finds a deployment that needs one. With none configured, no cross-origin credentialed read is allowed. Native clients send no `Origin` and are unaffected.
   Rejected: mirroring every origin. The server faces the public internet, and `SameSite=Lax` does not separate same-site siblings.
   Reverses: restore `allow_origins_matching(|_| true)`.
