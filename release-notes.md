## [1.0.0](https://github.com/justin13888/Beam/compare/v0.1.0...v1.0.0) (2026-09-28)


###   BREAKING CHANGES

* **server:** /v1 enum values, schema names and the health body change shape as listed above.
* **server:** GET /v1/continue-watching answers a ContinueWatchingConnection and takes first; GET /v1/history answers a HistoryConnection paged by first/after; their items carry Uuid ids, a media_type enum, played and last_played_at; PUT /v1/files/{file_id}/progress answers a UserTitleState. beam-client-core's history(first, after) returns a HistoryPage with end_cursor and has_next_page.
* **server:** GET /v1/media/{id}/sources returns {"items": [MediaSource...], "page_info": PageInfo} instead of a JSON array.
* **server:** one track model per source, a ranked primary, and subtitle delivery
* **index:** record codecs by FFmpeg's name and a subtitle's SDH flag
* **api:** page browse and search in the database
* **api:** capture the scan routes' library id as a UUID
* **api:** scanLibrary answers 202 with a ScanJob instead of 200 with {added}, and a second scan of a busy library is a 409.
* **client:** `BeamError::Server` gains a `retryable` field, so a foreign caller pattern-matching that variant has one more binding.
* **client-core:** `BeamError::{BadRequest, Forbidden, NotFound, Server}` gain a `code` field carrying the problem document's `type`, or
