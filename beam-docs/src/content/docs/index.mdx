## About this site

This site covers developer-facing notes that don't fit neatly in the main repository's `docs/`
tree. The canonical, actively-maintained engineering documentation -- requirements, architecture,
ADRs, per-component owner docs, testing strategy, and operations runbooks -- lives in
[`docs/`](https://github.com/justin13888/beam/tree/master/docs) in the main repository. Start
there for anything architectural.
