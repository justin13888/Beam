Beam runs as one server process alongside PostgreSQL. The repository ships a Compose file that
brings both up, along with the web app.

<Aside type="note" title="The default stack starts more than Beam">
The root `compose.yaml` also pulls in the development dependencies, which include **Traefik** —
binding host ports **80 and 443** and mounting the Docker socket read-only. If you already run
something on 80 or 443, or you do not want a container with access to the Docker socket, bring up
`compose.beam.yaml` and your own Postgres instead of the default `compose.yaml`.

The default stack starts **no identity provider**, so nobody can sign in until you configure one.
That is deliberate — Beam is bring-your-own-IdP. The bundled Dex test provider is opt-in behind
the `dev-idp` Compose profile and is for local development only.
</Aside>

<Aside type="caution" title="No release has been published yet">
Beam has never been tagged, so there are no published container images to pull. Compose builds
the images from the repository. The server image compiles FFmpeg from source, so **expect the
first build to take a long time.** Later builds reuse the layer cache.
</Aside>

## Bring up the stack

<Steps>

1. **Clone the repository.**

   ```bash
   git clone https://github.com/justin13888/beam.git
   cd beam
   ```

2. **Create your configuration.**

   ```bash
   cp .env.example .env
   ```

3. **Set the variables Beam cannot start without.** Edit `.env`. These are the ones that need a
   real value on any machine other than a throwaway local test — the defaults for everything else
   are fine to begin with.

   | Variable | What it is for |
   |---|---|
   | `POSTGRES_PASSWORD` | The database password. Change it from the default. |
   | `BEAM_DATABASE_URL` | How the server reaches Postgres. **Contains the password** — update it whenever you change `POSTGRES_PASSWORD`, or the server cannot connect. |
   | `HOST_VIDEO_DIR` | The directory on the host holding your media. |
   | `HOST_DATA_DIR` | Where Beam keeps its own writable state. |
   | `BEAM_SERVER_URL` | The URL browsers reach the server on. |
   | `BEAM_WEB_URL` | The URL browsers reach the web app on. |
   | `C_STREAM_SERVER_URL` | The API URL baked into the **web app**. See the warning below. |
   | `BEAM_OIDC_ISSUER` | Your identity provider's issuer URL. |
   | `BEAM_OIDC_CLIENT_ID` | The client ID you registered for Beam. |
   | `BEAM_OIDC_CLIENT_SECRET` | That client's secret. |
   | `BEAM_OIDC_ADMIN_CLAIM` | The ID-token claim that marks a user as an admin. |

   <Aside type="caution" title="C_STREAM_SERVER_URL is baked in at build time">
   The browser talks to the API directly, so the web app needs the API's public URL compiled into
   it. It is a **build argument**, not a runtime setting: changing it later means rebuilding the
   web image, not just restarting the container. Leave it at `http://localhost:8000` and a browser
   on any other machine will try to reach the API on its own loopback and fail.

   Do not point it at `http://<host>:8000` either. The server's port (`BEAM_SERVER_HOST_PORT`) is
   published on `127.0.0.1` only, so no other machine can reach it: the web app would load and
   then fail every API call. For browsers on other machines, set it to the reverse proxy's public
   origin for the server, which forwards the API's `/v1` routes and nothing else. The bundled
   Traefik serves that as `https://server.beam.localhost`, a name only this host resolves; give
   its router your own domain to serve other machines.
   </Aside>

   The three `BEAM_OIDC_*` credentials are required together — see
   [Identity provider and admin access](/operate/identity-and-access/) for how to register Beam
   with your provider. Without `BEAM_OIDC_ADMIN_CLAIM`, nobody is an admin.

   <Aside type="tip">
   Leave optional variables commented out rather than setting them to an empty string. Beam
   distinguishes "unset" from "set to empty", and an empty issuer URL reads as *OIDC is
   configured* — see the [configuration reference](/reference/configuration/).
   </Aside>

4. **Check your configuration before starting.**

   ```bash
   ./verify-config.sh
   ```

   This is a preflight that catches the variables Beam actually reads being missing or
   implausible.

5. **Start everything.**

   <Tabs syncKey="runtime">
     <TabItem label="Podman">
     ```bash
     podman compose up -d
     ```
     </TabItem>
     <TabItem label="Docker">
     ```bash
     docker compose up -d
     ```
     </TabItem>
   </Tabs>

6. **Confirm the server is healthy.**

   ```bash
   curl http://localhost:8000/v1/health
   ```

   A healthy server reports `"status":"healthy"` along with its version and uptime. If it reports
   `degraded`, the `checks` object names the failing dependency — see
   [Monitoring](/operate/monitoring/).

</Steps>

## Where things listen

| Service | Default | Variable |
|---|---|---|
| Web app | `http://localhost:8080`, on this host only | `WEB_HOST_PORT` |
| Web app through the bundled Traefik | `https://beam.localhost` | — |
| Server API | `http://localhost:8000`, on this host only | `BEAM_SERVER_HOST_PORT` |
| Server API through the bundled Traefik | `https://server.beam.localhost/v1` | — |
| Interactive API docs | `http://localhost:8000/openapi`, on this host only | — |

The server's port is bound to `127.0.0.1`: it carries every route, including the unauthenticated
`/metrics` and `/openapi`, so it is never published to the network. Other machines reach the API
through the reverse proxy, which forwards only `/v1`. The web app's port and Postgres's
(`POSTGRES_HOST_PORT`, for local tooling) are bound to `127.0.0.1` too: other machines reach the
web app through the reverse proxy over TLS, and nothing off this host reaches the database.

Open the web app and sign in. If sign-in fails, [Troubleshooting](/help/troubleshooting/) covers
the usual causes.

## Your media directory

`HOST_VIDEO_DIR` is mounted into the container at `BEAM_VIDEO_DIR`, read-only. Beam's indexer never
writes to it — it only reads — and the `:ro` in `compose.beam.yaml` means the container could not
write there even if something tried.
